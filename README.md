# paper-atlas

**Work in progress — not yet released.**

paper-atlas is a local tool for exploring the map of science. It renders an
interactive atlas of research fields, subfields, and topics — where
neighboring territories are the areas that cite each other most — and lets a
personal reference library (for example, a Zotero library) be overlaid on that
map to show which territories it covers and which nearby ones it does not.

The field/subfield/topic structure and the citation data come from
[OpenAlex](https://openalex.org), an open catalog of the global research
system. A full README with setup instructions, screenshots, scope, and
limitations will be written before the first release.
